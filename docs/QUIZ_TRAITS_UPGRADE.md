# 對卡特徵改版：答 2 條即出候選、軟計分、答錯一格唔會踢走正解

日期：2026-11-19 · 版本：3.2.0 → 3.3.0 → 3.4.0

## 問題（用家原話）

> 我發覺你那 5 問完全沒作用，像我想影大白鷺，白色 大隻 水鳥，加後兩題不記得是什麼也找不出來。

重現結果：大白鷺（NO.0242）真實特徵係「大／白／長嘴／涉禽／扇尾」。
用戶答「大＋白＋水鳥」，只要 Q4／Q5 撳錯一格（例如把「企水邊」當成「水中游」、
或尾形揀錯），**大白鷺就會完全消失**，即使大細、顏色、嘴形全中。

## 根因（三個，唔止一個）

1. **5 題硬性答完先准睇結果**：UI 要 `complete`（5 格齊）先出候選，
   而 Q4「鶲類／柳鶯／蘆鶯／鶇鶥」係鳥類學術語，Q5「尾形」由科硬推
   （鷺科一律「扇尾」），一般用戶等於冇得答 → 永遠卡住。
2. **Q4/Q5 係硬 filter**：`matchesAll5()` 全部要中，錯一格就 `filter` 走，
   之後嘅 36 隻上限更會把「答中自己特徵」嘅雀截走（有 89 隻同組）。
3. **資料失真**：鷺科 18 種全部標「白」（黑鳽、綠鷺、紫背葦鳽都變白），
   「白色＋大隻」呢組被一堆非白鷺塞滿。

### 2. 計分（`src/lib/birdFilter.ts`）

- `QUIZ_WEIGHTS = { size: 40, main_color: 40, spot: 30, beak: 15 }`，

- UI 文案老實：`poolSize`（真正全中數）同 `lowestHits`（有冇近似雀）分開講。
