# BIRD-DEX 2 (鳥精靈圖鑑)

BIRD-DEX 是一個結合「戶外生態觀察」與「卡牌收集養成」的 Web App。玩家必須親自走到戶外，用相機捕捉真實的鳥類，體驗如同寶可夢般的收集與升級樂趣！

## 🌟 核心特色 (Core Features)

1. **📷 實地探索與即拍即捉 (Explore & Snap)**
   - **強制現場實拍**：系統直接調用設備的後置實體鏡頭，不提供「相簿上傳」功能，鼓勵玩家真正走入大自然觀察。
   - 內建「離線影像感知引擎」，針對同一隻鳥的特徵會產出穩定的辨識結果。

2. **🔴 沉浸式捕捉體驗 (Capture Animation)**
   - 拍攝後，無論成功與否都會進入「丟出精靈球」的動畫流程。
   - **捕捉成功**：球搖晃三次後爆出星星特效，大喊 GOTCHA!
   - **捕捉失敗**：如果照片太模糊、太暗或距離太遠，精靈球搖晃後會「砰！」一聲爆出煙霧，鳥兒無情逃跑💨，增加挑戰真實感！

3. **🃏 閃卡與異圖系統 (Foil & Alt-Art Cards)**
   - **養成機制**：捕捉同種鳥類多次，該張卡牌的稀有度就會自動升級 (`UC -> C -> R -> SR -> SSR -> UR -> LR`)。
   - **全息閃卡特效**：到達 SR 等級以上，卡片表面會自動疊加程式運算的「全息反光 (Holographic Foil) 動態特效」，即使是原本的圖片也會變得閃閃發光！
   - **高階異圖支援**：當玩家將該鳥種升級到 UR（極稀，12次）或 LR（傳說，20次）等級時，系統支援自動替換成異圖版插畫（如 `1_UR.jpg`），完美重現 PTCG 抽中「滿版異圖卡」的成就感！

4. **🏆 訓練師成長系統 (Trainer Progression)**
   - 累積捕捉次數獲得 EXP，解鎖「見習觀鳥員」到「鳥精靈大師」等專屬稱號。
   - 升級可更換個人頭像（如解鎖望遠鏡🔭、專業相機📷等裝備）。

5. **🗄️ JSON 資料驅動 (Database)**
   - 核心圖鑑資料維護於 `birds.json`。圖片統一放置於 `public/birds/` 目錄下透過編號直接讀取，便於管理與擴充。
